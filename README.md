# Лабораторная работа №1: Знакомство с Flutter. Создание базового UI

## Описание
Данный проект создан в рамках выполнения лабораторной работы №1 по курсу мобильной разработки.  
Цель работы — освоить базовые навыки работы с фреймворком Flutter: настройку среды, создание простого пользовательского интерфейса с использованием виджетов `Scaffold`, `Column`, `Row`, `Container`, `Text`, `FloatingActionButton` и `CircleAvatar`, а также добавление интерактивности и сетевых изображений.

## Структура интерфейса
- Верхняя часть: красный и зелёный контейнеры.
- Средняя часть: три текстовых элемента, равномерно распределённые по ширине.
- Нижняя часть (занимающая оставшееся пространство): два круглых аватара, один из которых отображает изображение из интернета.
- Плавающая кнопка в правом нижнем углу выводит сообщение в консоль при нажатии.
